# ZoomRide_SQL_Analysis

## PROJECT OVERVIEW
This project focuses on cleaning and analyzing ZoomRide data using SQL to discover meaningful business insights.
It began with data preparation, correcting spelling inconsistencies, removing duplicate records, eliminating excess spaces to improve data quality.

This project goal is to transform raw data into clear, actionable insights that can help ZoomRide better understand its customers, revenue performance, and trip operations.

--- 

## BUSINESS QUESTIONS ANSWERED
- Question 1. Which city earns the most money?
- Question 2. Which month do people ride the most?
- Question 3. Which type of vehicles earns the most money?  

---

## DATABASE STRUCTURE
- Table 1. trips- Stores trip information and connects customers and drivers.
- Table 2. customers- Contains customers information.
- Table 3. drivers- Contains drivers information.

## PROJECT OUTPUT
The project produced a cleaned and structured relational database along with SQL queries that answers key business questions.
The analysis generated results covering total trip count, customers activity, revenue performance, and ride characteristics.
---

## KEY INSIGHTS
- Lagos city generated the highest revenue.
- December 2025 recorded the highest revenue and trips volume.
- Economy vehicle was the top performing vehicle type generating high revenue.
